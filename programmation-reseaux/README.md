# Programmation réseau

Programmation des sockets en C sous Linux (3A STI).

| Dossier | Contenu |
|---|---|
| [`td/td01-client-ntp/`](td/td01-client-ntp/) | Client NTP en UDP : structure du paquet NTP, `socket`, `gethostbyname`, `sendto` / `recvfrom` |

## Compilation

```sh
make            # compile tous les TD
make clean
```

Chaque TD produit un exécutable par fichier `src/*.c` dans son dossier `bin/`.
