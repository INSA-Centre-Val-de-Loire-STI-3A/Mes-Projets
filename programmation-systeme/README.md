# Programmation système

Programmation système en C / POSIX sous Linux (3A STI).

| Dossier | Contenu |
|---|---|
| [`td/td01-appels-systeme/`](td/td01-appels-systeme/) | Appels système bruts avec `syscall`, gestion des erreurs avec `errno`, `perror` et `strerror` |

## Compilation

```sh
make            # compile tous les TD
make clean
```

Chaque TD produit un exécutable par fichier `src/*.c` dans son dossier `bin/`.
